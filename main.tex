% ===================== 1. INTRODUCTION =====================
\section{Introduction}

Dans un r\'eseau de t\'el\'ephonie mobile, la couverture g\'eographique est assur\'ee par un ensemble de cellules radio juxtapos\'ees. Chaque cellule est g\'er\'ee par une station de base (BTS en GSM, eNodeB en LTE) qui dialogue avec les terminaux mobiles pr\'esents dans sa zone. Pour acheminer les communications, le terminal s'attache \`a une cellule principale appel\'ee cellule serveuse, tout en surveillant le niveau de signal re\c{c}u pour pr\'eparer d'\'eventuels changements d'antenne (handover).

Ce TP a pour but d'analyser le comportement de cette liaison sur un smartphone connect\'e aux r\'eseaux cellulaires r\'eels. \`A l'aide des applications Android Cell Monitor et Cell Signal Monitoring, nous identifions d'abord les param\`etres techniques de la cellule serveuse en LTE et en 2G (Partie A), avant d'\'etudier l'impact de l'environnement physique sur la puissance du signal re\c{c}u (Partie B).

% ===================== 2. MATÉRIEL ET MÉTHODE =====================
\section{Mat\'eriel et m\'ethode}

Les mesures ont \'et\'e effectu\'ees en salle de TP et dans les b\^atiments de l'\'ecole avec le mat\'eriel suivant :
\begin{itemize}
    \item \textbf{Terminal mobile :} Smartphone OPPO A3s (mod\`ele CPH1803), fonctionnant sous Android 8.1.0 ;
    \item \textbf{Cartes SIM :} Deux cartes SIM actives d'op\'erateurs distincts : SIM 1 sur le r\'eseau Yas (Telma) et SIM 2 sur le r\'eseau Orange Madagascar ;

Le r\'ecepteur GPS du terminal a \'et\'e activ\'e conform\'ement aux exigences d'Android pour acc\'eder aux informations radio. Les donn\'ees personnelles comme les num\'eros IMEI et de ligne priv\'ee sont masqu\'ees sur les captures d'\'ecran.

\subsection{R\'eponses d\'etaill\'ees aux questions de la Partie A}

\paragraph{1. Identification du pays et des op\'erateurs \`a partir du MCC et du MNC}
Le code MCC (Mobile Country Code) 646 identifie Madagascar selon le plan de num\'erotation international ITU E.212. Le code MNC (Mobile Network Code) distingue l'op\'erateur national :
\begin{itemize}
    \item Pour la SIM 1, le couple 646 / 04 correspond au r\'eseau Telma Mobile, commercialis\'e sous la marque Yas affich\'ee par le t\'el\'ephone ;
    \item Pour la SIM 2, le couple 646 / 02 correspond au r\'eseau Orange Madagascar.
\end{itemize}

\paragraph{2. Calcul des fr\'equences montante et descendante des canaux 2G}
\begin{itemize}
    \item \textbf{Pour Yas (ARFCN 66) :} Le canal 66 est situ\'e dans la bande GSM 900 standard ($n \in [1, 124]$). Les fr\'equences se calculent ainsi :
    \begin{align}
        F_{\text{montante}} &= 890 + 0{,}2 \times 66 = 903{,}2\text{ MHz} \\
        F_{\text{descendante}} &= F_{\text{montante}} + 45 = 948{,}2\text{ MHz}
    \end{align}
    La cellule Yas \'emet donc avec une fr\'equence voie descendante de 948,2 MHz et une voie montante de 903,2 MHz.

    \item \textbf{Pour Orange (ARFCN 881) :} Le canal 881 appartient \`a la bande DCS 1800 ($n \in [512, 885]$). Les relations de calcul sont :
    \begin{align}
        F_{\text{montante}} &= 1710{,}2 + 0{,}2 \times (881 - 512) = 1710{,}2 + 73{,}8 = 1784{,}0\text{ MHz} \\
        F_{\text{descendante}} &= F_{\text{montante}} + 95 = 1879{,}0\text{ MHz}
    \end{align}
    La cellule Orange fonctionne donc \`a 1784,0 MHz en liaison montante et 1879,0 MHz en liaison descendante.
\end{itemize}

\paragraph{3. V\'erification de la coh\'erence entre dBm et ASU}
Sur le mod\`ele OPPO A3s utilis\'e lors de cette s\'erie de mesures 2G, les applications n'ont pas affich\'e la valeur enti\`ere d'ASU. La formule th\'eorique d'Android pour le GSM est :
\begin{equation}
    P_{\text{dBm}} = 2 \times \text{ASU} - 113
\end{equation}
Faute de valeur ASU transmise par l'API du t\'el\'ephone lors de cette mesure, aucune valeur n'a \'et\'e invent\'ee, conform\'ement aux consignes de rigueur scientifique.

\paragraph{4. D\'ecomposition de l'identifiant ECI en LTE}
En 4G, les applications pr\'esentent l'identifiant sous une forme scind\'ee :
\begin{itemize}
    \item Pour Orange, la mention affich\'ee \texttt{37083-1} correspond \`a un $\text{eNB ID} = 37083$ et un $\text{Cell ID local} = 1$. L'identifiant ECI total s'obtient par la formule standard :
    \begin{equation}
        \text{ECI} = \text{eNB ID} \times 256 + \text{Cell ID local} = 37083 \times 256 + 1 = 9\,493\,249
    \end{equation}
    \item Pour Yas, la mention \texttt{413137-11} correspond \`a un $\text{eNB ID} = 413137$ et un $\text{Cell ID local} = 11$. L'ECI total calcul\'e vaut :
    \begin{equation}
        \text{ECI} = 413137 \times 256 + 11 = 105\,763\,083
    \end{equation}
\end{itemize}
L'eNB ID identifie la station de base physique (le site radio g\'er\'e par l'op\'erateur), tandis que le Cell ID local d\'esigne le secteur d'antenne couvrant la zone o\`u nous nous trouvons.

\paragraph{5. \'Ecriture du code CGI complet des cellules 2G}
Le CGI (Cell Global Identity) regroupe le code pays, le code op\'erateur, le code de zone et le num\'ero de cellule ($\text{CGI} = \text{MCC}-\text{MNC}-\text{LAC}-\text{CID}$) :
\begin{itemize}
    \item Pour la cellule Yas : $\text{CGI} = \text{646-04-14110-64371}$ ;
    \item Pour la cellule Orange : $\text{CGI} = \text{646-02-3010-33491}$.
\end{itemize}

\paragraph{6. R\^ole du LAC face au CID}
Le code LAC d\'elimite une zone de localisation qui englobe un grand nombre de cellules. Le t\'el\'ephone signale son d\'eplacement au r\'eseau coeur (proc\'edure de Location Update) seulement quand il traverse la fronti\`ere d'un LAC. En se d\'epla\c{c}ant dans un m\^eme quartier, le terminal change fr\'equemment de cellule pour s'accrocher \`a la plus puissante (le CID change), mais il conserve le m\^eme LAC. Cela \'evite de surcharger le r\'eseau avec des messages de signalisation \`a chaque changement de secteur.

\subsection{Analyse des r\'esultats}

\paragraph{1. Commentaire des \'ecarts observ\'es}
Le graphique montre l'influence directe de la configuration des lieux sur la r\'eception radio :
\begin{itemize}
    \item Les niveaux les plus forts sont observ\'es en ext\'erieur ($-68\text{ dBm}$) et au dernier \'etage ($-71\text{ dBm}$), car le terminal profite d'un trajet peu encombr\'e vers l'antenne-relais ;
    \item La puissance d\'ecro\^it rapidement d\`es que l'on s'enfonce dans le b\^atiment : le signal passe de $-76\text{ dBm}$ pr\`es de la fen\^etre \`a $-87\text{ dBm}$ dans la salle et $-94\text{ dBm}$ dans le couloir ;
    \item Le sous-sol est le lieu le plus p\'enalisant ($-105\text{ dBm}$), en raison de l'\'epaisseur des dalles de b\'eton arm\'e qui bloquent la propagation.
\end{itemize}

\paragraph{2. Affaiblissement d\^u \`a la p\'en\'etration dans le b\^atiment}
La perte li\'ee \`a la travers\'ee des parois se d\'eduit de la diff\'erence entre l'ext\'erieur (point 1) et le centre de la salle (point 3) :
\begin{equation}
    L_{\text{b\^atiment}} = P_{\text{ext}} - P_{\text{salle}} = (-68\text{ dBm}) - (-87\text{ dBm}) = 19\text{ dB}
\end{equation}
Cette valeur de 19 dB concorde avec les ordres de grandeur habituels en t\'el\'ephonie mobile, o\`u l'att\'enuation d'un b\^atiment standard se situe entre 10 et 20 dB.

\paragraph{3. \'Evanouissement lent et \'evanouissement rapide}
L'enregistrement de la marche (capture B3) montre la superposition de deux m\'ecanismes physiques distincts :
\begin{itemize}
    \item \textbf{L'\'evanouissement lent (effet de masque) :} La tendance moyenne du signal varie sur plusieurs dizaines de m\`etres lorsque de gros obstacles (murs porteurs, b\^atiments voisins) masquent la ligne de vis\'ee directe.
    \item \textbf{L'\'evanouissement rapide (multi-trajets) :} De fortes fluctuations de 10 \`a 20 dB se succ\`edent sur de tr\`es courtes distances. Elles r\'esultent des r\'eflexions de l'onde sur les surfaces environnantes. Les diff\'erents rayons arrivent d\'ephas\'es sur l'antenne du t\'el\'ephone et se combinent de mani\`ere constructive ou destructive.
\end{itemize}

\paragraph{4. Effet de la main ferm\'ee sur le terminal}
En serrant la main autour du smartphone, la puissance re\c{c}ue chute de 10 dB. Le corps humain est en grande partie compos\'e d'eau, un milieu qui absorbe une fraction notable de l'\'energie \'electromagn\'etique dans les bandes de fr\'equences mobiles (900 \`a 2600 MHz). De plus, la proximit\'e de la main modifie l'imp\'edance de l'antenne int\'egr\'ee, ce qui alt\`ere son accord et d\'egrade son rendement.

\paragraph{5. \'Ecarts en d\'ecibels et rapports de puissance}
La conversion d'un \'ecart en dB vers un rapport de puissance lin\'eaire s'obtient par la formule :
\begin{equation}
    \Delta P_{\text{dB}} = 10 \log_{10}\left(\frac{P_2}{P_1}\right) \iff \frac{P_2}{P_1} = 10^{\frac{\Delta P_{\text{dB}}}{10}}
\end{equation}
\begin{itemize}
    \item Pour un \'ecart de 3 dB : $\frac{P_2}{P_1} = 10^{0{,}3} \approx 2$. Une variation de 3 dB correspond \`a doubler ou diviser par deux la puissance.
    \item Pour un \'ecart de 10 dB : $\frac{P_2}{P_1} = 10^1 = 10$. La puissance est multipli\'ee ou divis\'ee exactement par dix.
    \item En comparant l'ext\'erieur ($-68\text{ dBm}$) et la salle ($-87\text{ dBm}$), la diff\'erence est de 19 dB :
    \begin{equation}
        \frac{P_{\text{ext}}}{P_{\text{salle}}} = 10^{1{,}9} \approx 79{,}4
    \end{equation}
    Le signal ext\'erieur est ainsi environ 80 fois plus puissant que le signal re\c{c}u dans la pi\`ece.
\end{itemize}

\paragraph{6. Limites de la seule mesure de niveau de signal}
Un niveau de signal \'elev\'e ne garantit pas \`a lui seul une communication fluide. Si le canal est encombr\'e par du bruit ou des interf\'erences provenant d'autres antennes \'emettant sur la m\^eme fr\'equence, la voix peut \^etre hach\'ee et les donn\'ees corrompues.

D'autres grandeurs sont n\'ecessaires pour \'evaluer la liaison :
\begin{itemize}
    \item \textbf{RxQual en GSM :} Cet indice de 0 \`a 7 mesure le taux d'erreurs sur les bits re\c{c}us (BER) avant correction ;
    \item \textbf{SINR en 4G LTE :} Ce rapport compare la puissance du signal utile \`a la somme du bruit et des interf\'erences ;
    \item \textbf{RSRQ en 4G LTE :} Il mesure la qualit\'e des signaux de r\'ef\'erence en tenant compte de la charge du r\'eseau.
\end{itemize}

En 4G, de l\'egers \'ecarts de quelques dB peuvent appara\^itre sur le niveau de signal instantan\'e. Ils s'expliquent par un rafra\^ichissement non strictement synchrone et par un \'eventuel filtrage num\'erique interne appliqu\'e par Cell Signal Monitoring pour stabiliser sa courbe.

\paragraph{2. Recommandation d'usage}
Cell Monitor est id\'eale pour relever rapidement les param\`etres d'infrastructure d'une station (canaux ARFCN, codes de zone, identifiants complets). Cell Signal Monitoring est en revanche bien plus pratique pour les campagnes de mesure en marchant, car sa courbe en direct permet de rep\'erer imm\'ediatement les baisses de niveau et les coupures.

% ===================== 6. CONCLUSION =====================
\section{Conclusion}

Ce travail pratique a permis de v\'erifier concr\`etement les notions li\'ees \`a l'architecture cellulaire et \`a la propagation radio \`a partir de mesures r\'ealis\'ees sur smartphone.

L'identification men\'ee en Partie A met en lumi\`ere le r\^ole cl\'e des param\`etres standardis\'es. La d\'ecomposition du CGI et de l'ECI d\'emontre comment les op\'erateurs structurent leurs r\'eseaux pour localiser pr\'ecis\'ement chaque cellule dans le monde. Les calculs de fr\'equence confirment que les op\'erateurs locaux exploitent la bande GSM 900 (pour Yas) et la bande DCS 1800 (pour Orange).

L'\'etude exp\'erimentale de la Partie B illustre l'effet d\'eterminant de l'environnement sur la r\'eception : la p\'en\'etration dans un b\^atiment entra\^ine une perte de 19 dB, tandis que la tenue du t\'el\'ephone \`a pleine main d\'egrade le signal d'environ 10 dB. Enfin, la comparaison des deux applications montre qu'elles se compl\`etent efficacement pour le diagnostic et le suivi d'un r\'eseau cellulaire.

\section*{Annexe : Glossaire des sigles}
\addcontentsline{toc}{section}{Annexe : Glossaire des sigles}

\begin{itemize}[leftmargin=2.5cm, labelsep=0.5cm]
    \item[\textbf{ARFCN :}] Absolute Radio Frequency Channel Number, num\'ero de canal d\'eterminant les fr\'equences d'\'emission et de r\'eception en GSM.
    \item[\textbf{ASU :}] Arbitrary Strength Unit, valeur enti\`ere d\'efinie sous Android refl\'etant la puissance du signal.
    \item[\textbf{BSIC :}] Base Station Identity Code, identifiant local de la station de base en GSM.
    \item[\textbf{BTS :}] Base Transceiver Station, antenne-relais et station de base en r\'eseau 2G.
    \item[\textbf{CGI :}] Cell Global Identity, identifiant unique mondial d'une cellule radio ($\text{MCC}+\text{MNC}+\text{LAC}+\text{CID}$).
    \item[\textbf{EARFCN :}] E-UTRA Absolute Radio Frequency Channel Number, canal radio utilis\'e en 4G LTE.
    \item[\textbf{eNodeB :}] Evolved Node B, station de base des r\'eseaux 4G LTE.
    \item[\textbf{LAC :}] Location Area Code, code identifiant une zone g\'eographique de mobilit\'e en 2G/3G.
    \item[\textbf{PCI :}] Physical Cell Identity, identifiant physique de la cellule en LTE.
    \item[\textbf{RSRP :}] Reference Signal Received Power, puissance re\c{c}ue des symboles pilotes en 4G LTE.
    \item[\textbf{RSRQ :}] Reference Signal Received Quality, indicateur de la qualit\'e des signaux de r\'ef\'erence en LTE.
    \item[\textbf{RSSI :}] Received Signal Strength Indicator, puissance radio totale re\c{c}ue.
    \item[\textbf{SINR :}] Signal to Interference plus Noise Ratio, rapport signal sur bruit plus interf\'erences.
    \item[\textbf{TAC :}] Tracking Area Code, \'equivalent en 4G du code de zone de localisation (LAC).
\end{itemize}
